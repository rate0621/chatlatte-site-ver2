# ボイスプロファイル（chatlatte運営者の人格・語り口）

インタビュー・記事制作のたびに参照し、新しい発見があれば本人確認のうえ追記する。
記事の「らしさ」の源泉。ここに無い人格を創作しないこと。

## 話し方の癖

- 断定を避ける柔らかい語尾：「〜かな」「〜と思います」「〜な気がします」「〜でしょうかね」
- 数字や記憶に誠実で、盛らない：「だいたい半日はかかってたと思います」「〜とは思いますが」と幅を残す
- 口語のリズム：「〜のよね」「〜って感じかな」。カジュアルだが軽薄ではない
- 手柄話を自分から膨らませない。実績も「〜した感じかな」と流す傾向（記事側で数字の意味を補う必要がある）

## 価値観・思想（2026-07-05 第1回インタビューより）

- **技術に固執しない**：ツールを作ることではなく困りごとが消えることがゴール（サイトの信条と一致）
- **AIと人間の役割分担のサンドイッチ論**：「人がルールを決める → AIが作業する → 人が確認する」。ルールやブランドを守るのは人間の役目という信念
- **「人間の知恵を使うための時間」を尊ぶ**：自動化の価値を「時間削減」ではなく「人がより頭を使う仕事に移れること」に置く
- **現場のプロへの敬意**：コンテンツの質の判断はコンテンツチームに委ね、レビューを何度も「お願いした」。自分が全部決めない
- **提案は押し付けない**：「定例でそういう話が出たのでフラットに提案してみた」という関わり方を自認。「俺がすごい」的な文脈を強く嫌う

## 行動パターン

- 困りごとを近くで聞いていて、頼まれる前に軽く提案する（定例会議の雑談から仕事が生まれる）
- 作るのは速い（動くものは1日）が、質の調整には粘り強く時間をかける
- 導入して終わりにせず、効果測定（流入分析など）まで見る

## 記事化するときの注意

- 「相手は」ではなく「ご一緒していた」——関係者は常に協働の距離感で
- 自分の貢献は「軽く提案してみました」程度の自然な言及にとどめる（念押し説明はNG）
- 顧客名・具体的なサービス名は出さない（CMS、クラウド等の一般名詞に置き換える）
