# X投稿（本文）

私はいま、山形に住みながら都市部の仕事をしています。「わざわざ山形に？」と聞かれることもあるんですが、順番としては、先に働き方が決まって、住む場所は後から選びました。

移住前は千葉にいました。当時のクライアントとはその頃からずっとリモートで、今もお付き合いが続いています。これから先もこうやってリモートで働きたいなと思ったとき、ふと「それなら千葉にいる理由もないな」と気づいたんです。

移住先は、旅行がてら長野・静岡・富山も回りました。その中で山形が一番よかった。決め手は、いま思うとずいぶん生活者の目線でした。最初に入ったラーメン屋が美味しかったこと。道路が広くて、運転する人も丁寧だったこと。周りが山に囲まれていて、どこか安心感があったこと。仕事はどこでもできる前提だったからこそ、「暮らしやすいか」だけで選べたんだと思います。

働いてみて、やりにくさはありません。月1で出社はしていますが（新幹線です）、強制ではなく、都合が悪ければ行かなくていい。義務にしないほうが、逆にみんな集まりやすい気がします。毎日出社だと集中が途切れることもあるし、月1くらいがちょうどいい。リモートか出社かの二択じゃなく、ちょうどいい頻度を探す感覚に近いです。

ただ、安易に「移住はいいぞ」とは言えないんですよね。今はいい、というだけで。急にリモートで働けなくなるかもしれないし、契約を切られることだってある。その不安は必ずあります。

それでも、自分がどう働きたいか、それに従って生きたほうがいいと思っています。年をとって「本当はこうしたかった、でも今からじゃもう……」となるのが、一番寂しいので。

続きはブログに書きました。
