# X投稿（本文）

最近、「日本人、ちょっと病んでないかな」と思うことがありました。きっかけはポケモンカードです。

ポケカを始めて、界隈の情報をXで見るようになったんですが、お店が購入条件にポケカのクイズを出して、答えられない人（＝転売ヤー）を弾く、という対応をしているところがあるんですね。それを見物した人の投稿が、こんな感じでした。「クイズで転売ヤーが弾かれてて虚無顔で列から外れるのメシウマすぎだろ」「しばらく見学させていただいたわ」「癖になりそう」。

読んだときの最初の反応は、「引いた」でした。

先に言っておくと、喜びたくなる気持ち自体は分かるんです。買えなかった悔しさの反動もあるし、ズルをした人がちゃんと罰を受けた、という正義の快感もある。そこを責めるつもりはありません。

引っかかったのは、もう少し細かいところで。相手が弾かれて「自分が買える」ことを喜んでいるなら分かる。自分の得が増えた話ですから。でも流れてくる投稿の多くは、そうじゃない気がしました。「相手が買えなくなったこと自体」が嬉しい。自分が買えるかどうかとは関係ないところで、他人が損をする様子そのものが娯楽になっている。それはなんか、人として心が貧しくないかな、と思ってしまったんです。

そう思って見てみると、これはポケカの話に限らなくて。Xを見ていて常々、「なんでこの人たちって、自分にとって得も損もしないのに、他人が炎上したり不幸になったりしているニュースに飛びつくんだろう」と思っていました。たぶん、幸福を相対的に見ているんだと思います。自分は何も持っていないんだけど、それより下を見ることで幸せな気持ちになっている。もうひとつは、「こいつは悪いことをしている（らしいし）石を投げてもいい」という考え。イジメは良くないって子供に教えつつ、当の大人たちがイジメをしたくて仕方ない、という感じになっている気がするんですよね。

じゃあ自分はどうしているかというと、測る範囲を決めています。自分に関わりのある人の範囲内で、自分は何ができているのかを考える。家族、仕事仲間、友達。そのくらいの半径です。

他人の不幸を喜ぶ気持ち自体は、誰の中にもある普通のものだと思います。ただXを見ていると、どうも量が過剰な気がしていて。この一週間、誰かの損をながめた時間と、自分の半径の中で何かができた時間、どちらが長かったでしょうか。
