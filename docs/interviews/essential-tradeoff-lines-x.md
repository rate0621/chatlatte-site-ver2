# X投稿（本文）

『エッセンシャル思考』を読んで、一番「これ自分もやってるな」と思ったのが取捨選択の話でした。

本に「単にノーと言うのが難しければ、相手にトレードオフを意識させよう。『では今の仕事のどれを後回しに？』と」という一節があるんですが、これ、僕がふだんやってることに近い。

お客さんから「あれもお願い」が来たとき、まず「いいですね！」と依頼を肯定する。そのうえで「ただ今この作業も進行中で。どっちを先にやりますか？」と正直に返す。

さらにその別作業が"別の人からの依頼"なら、「じゃあ、あなたからあの人に『こっち優先するのでそちらの納期は遅れます』と伝えてください」とまで持ってもらう。

トレードオフを「どっち優先？」の言葉じゃなく、"他の人に頭を下げる手間"として相手に返すと、本当に今すぐ必要かが相手の側でもはっきりするんですよね。

大事なのは、最初に「いいですね！」と肯定すること。「別にやりたくないわけじゃない」を先に伝えないと、ただの拒絶になる。順番として肯定が先。それだけで角が立ちにくくなります。

あと、本には「一度でも例外を許したら例外だらけになる。線引きは砂の壁だ」ともあるんですが——正直これは言い過ぎだと思っています。

僕は緊急なら線を破る（今やらないと障害になる時とか）。でも「これは例外」とはっきり伝えれば、例外だらけにはならない。強めに書いてある主張は「それくらいの構えでいけ」くらいに受け取って、あとは自分の現場で程度を決める。そのほうがずっと使えます。
