# X投稿（本文）

「副業はすべき」「これからは副業の時代」「一社依存は危険」——この手の声に、正直ずっと引っかかっています。副業そのものにではなく、それを外から言ってくる人のほうに。

副業をやるかどうかって、本来は完全に本人の問題ですよね。やるのも自分だし、うまくいかなかったときにリスクを負うのも自分。なのに、身銭も切らない、リスクも取らない他人が、他人に向かって「副業はすべきだ」と言ってくる。ここがどうも引っかかる。だってその人は、あなたが副業で疲れ切っても、本業に支障が出ても、思ったより稼げなくても、何の責任も取ってくれません。押すだけ押して、あとは知らんぷりです。

ちなみに僕自身は、会社員時代は副業をしていませんでした。フリーランスになってからも基本は1案件。ただ、たまに掛け持ちはしました。きっかけも「副業やるぞ」ではなく、知り合いが産休・育休に入る間、代わりに入ってほしいと頼まれた、それだけです。良かったのは、収入が増えたことと、片方の案件で得た知見をもう片方に展開できたこと。同時に二つ見ていると、片方だけでは気づけないことに気づける瞬間がある。これは面白かった。

ただ、良いことばかりでもありません。副業で求められるのは、要するに即戦力です。曖昧な依頼を自分で咀嚼して「こういうことですね、やっておきます」と動ける人でないと、正直きつい。「次は何をすれば？」と指示を待つタイプには向いていません。会社はそこの面倒までは見てくれないので。

じゃあ「副業したほうがいいのかな」と迷う人には何と言うか。僕はいつも、その迷いが"どこから来ているか"次第だと思っています。「周りがすべきと言うから」ならやめておいたほうがいい。リスクを負うのは自分なのに、動機が他人のものだから。逆に、自分なりの考えがあるなら、リスクに見合う対価はあるし、覚悟があるならどんどんやればいい。

「すべき」でも「するな」でもない。動機が自分の中から来ているか。線はそこだけだと思います。
