# X投稿（本文）

『GIVE & TAKE』にこんな一節があります。「ギバーは『記録』より『記憶』を重んじる。恩恵とは思いがけず来るものであり、事前に期待したり損得勘定するものではない」。

私はちょっとした修正くらいなら無料でやってしまうことが多いので、この一節は自分のことのようでもあり——でも当てはめると、少しズレる感じもしました。

正直に言うと、無料で何かをやるとき、損得をまったく忘れてるわけではないんです。「これはいつか返ってくるかもな」という考えが浮かばないわけじゃない。

ただ「後で見返りがあるからやる」と意識して動いてるかというと、それは違う。仮に絶対返ってこないと分かっていても、その時「これはやるべきだ」と感じればたぶんやると思います。動いてるのは見返りの計算じゃなくて、その場の「やるべきかどうか」のほう。

じゃあその「やるべき」は何かというと、案件の中ではけっこう単純で、今やらないと事業がマイナスを出し続けるとか、クレームにすぐ対応しないといけないとか。切実な必要があるからやる。

案件の外で相談に乗ることもあるけど、こっちは自分の感覚だと「与えている」というより、ただ雑談してるだけに近い。相談に乗ってあげてる、という意識が正直あまりないんですよね。

ここまで考えて、しっくりくる言い方が見つかりました。私は「損得勘定をしないギバー」というより、そもそも損得を勘定する土俵に立っていないだけなのかもしれない。立派な心がけじゃなくて、たぶんこれが一番自然なだけで。
