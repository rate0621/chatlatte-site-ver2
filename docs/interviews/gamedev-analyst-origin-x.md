# X投稿（本文）

大学も出ていない。統計の知識もない。

それでも前職の面接で「データ分析ができるエンジニアが欲しい」と言われたとき、「それでも良ければやります」と答えて、データアナリストになりました。

別の大手IT企業からも内定はもらっていたんですが、そっちより課題感があって楽しそうだったので。不安は特になかったです。基本的に「なんとかなるだろう」って思ってしまう性格なので。

実際、統計の知識でつまずいたことはあまりなかったんですよね。つまずいたのは全然別のところでした。

ソシャゲ会社には「プランナー」と呼ばれる、イベントを企画する人たちがいるんですが、彼らからよく来る依頼が「このイベントの成果を知りたい」というもの。

ただ、「どう見たいか」までは言ってこない。というかそこまでのイメージが本人たちにもないんです。漠然と「成果が知りたい」とだけ言ってくる。

最初は「見たいのはあなたなんだから、教えてよ」って正直思ってました。

でもある時から「相手が出してこないなら、こっちから出せばいいや」と諦めて、自分から「こういうアウトプットの形でいいですか」と提案する側に回るようになったんです。

そこから、数字が芳しくないイベントでも「切り口を変えると、別の良い面が見えてくる」ことに気づいていって——

このへんの話、実は今の仕事にもそのままつながってたりします。続きはブログに書きました。
