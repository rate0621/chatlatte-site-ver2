# X版：生成AI定着しない問題

## 本文ポスト（コピペ用・リンクなし）

「社員全員が生成AIを使いこなす組織」は、あきらめていいと思っています。

総務省の白書だと、日本企業の55.2%が生成AIを利用しているそうです。ただ中身の中心は「メール・議事録・資料作成の補助」。現場で見てきた実感とも合っていて、スローガンと支援があっても、実際に使っているのはほんの一部だったりします。

面白いのが、「AI使ってますよ」と言う人からの相談です。その質問、AIに聞けばすぐ分かるのにな…と思いながら、私が代わりにAIに聞いて、答えを噛み砕いて伝えていたりします。「利用率55.2%」の中身って、けっこうこういう感じなんじゃないでしょうか。

使わない理由もだいたい見えていて、新しいツールに「慣れる時間」が惜しいんですよね。人に聞いたほうが早いと思っている。優秀な人ほど「自分でやれちゃう」から頼らない。長期的に見れば絶対に間違ってるんですけど、気持ちは分かります。

ちなみに「補助止まり」自体は悪くないと思っています。うちも夫婦で「角の立たない返信つくって」ってAIに頼みますし、ああいう小さな成功体験から「これも任せられるかな」が始まるので。

ただ、これだけ便利なものが目の前にあっても使わない人は、何を言っても使いません。そこはドライに受け入れたほうがいい。「使ってね」だけじゃ人は動かないです。

じゃあ会社はどうするか。私の答えは、AIを「人に覚えさせる」のではなく「業務の仕組みに埋め込む」です。

以前、AI自動化で月150時間削減した現場では、使う人はAIに慣れる必要がありませんでした。記事にチェックを付けて「作成」を押して、確認して「入稿」を押すだけ。プロンプトは一文字も書いていません。AIに興味がない人の手元にも、恩恵だけが届く形です。

もっと軽い始め方なら、定例会議で「AIにも聞いてみます」と言って、AIを議論の参加者にしてしまうのもおすすめです。導入コストゼロで、「AIと働く」感覚がチームに広がっていきます。
