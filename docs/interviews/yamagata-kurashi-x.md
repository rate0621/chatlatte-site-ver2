# X投稿（本文）

山形に移住して、地味に「これいいな」と思うことがいくつかあります。派手な話じゃないんですが、暮らしの話を。

まずラーメン。近所のお店にふらっと入っても、だいたいどこも美味しい。外れを引いた記憶があまりない。

あとで知ったんですが、山形市ってラーメンの消費額が日本一だそうです。総務省の家計調査で、しかも何年も連続1位。2位3位を大きく引き離してるらしく、そりゃレベルも上がるよな、と納得しました。なんで美味いのかなと考えると、たぶん水がいいからじゃないかな。雪解け水や湧き水が豊富で、水が美味しい土地だと言われてるので。ラーメンってスープのほとんど水ですしね。まあ素人の推測ですが。

もう一つが、山に囲まれてる「謎の安心感」。うまく言葉にできないんですが、あえて言うなら"自然をちゃんと感じられてる証"みたいなものかも。東京や千葉にいた頃は、正直あまり自然を感じる瞬間がなかった。今は視界のどこかに必ず山がある。それだけで落ち着くんですよね。

その山、毎日見てると日によって顔つきがちがうんです。緑が深い日、葉っぱがもさっと茂って見える日。同じ季節・同じ山なのに昨日と今日で全然ちがう。「お、今日はこういう顔か」と眺めるのが、地味に好きな時間です。

人に自慢するほどのことじゃないけど、こういう小さな「いいな」が毎日いくつかある。それが自分には合ってるんだろうなと思います。
