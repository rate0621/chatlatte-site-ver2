# X投稿（本文）

「AIが若手の仕事を奪う」って話題ですよね。スタンフォードの研究で、AIにさらされる職種で若手（22〜25歳）の雇用が約13%減、ベテランはほぼ減ってない、と。

奪われるのは分かる。でも僕がまず思ったのは「その"雇用が減った"って、具体的に何が減ったの？」でした。社員をクビにしたのか、採用を絞ったのかで、意味が全然ちがう。

調べたら答えははっきりしてました。クビ（レイオフ）じゃなく、採用が細ってる。今いる若手を切ってるんじゃなくて、欠員が出てもエントリー級を若手で埋め直さなくなってる。「キャリアの梯子の一番下の段が、静かに外されてる」。

しかも減ってるのはAIが"置き換えられる"仕事で、AIを"補助に使う"仕事はむしろ増えてる。置き換わるのは定型コーディングや一次対応みたいな"手順の仕事"＝若手が経験を積む入口。残る（増える）のは問いを立てる・判断する・責任を持つ仕事。

難しいのは、その"問いと判断力"って、本来は入口の作業で失敗しながら育つものだってこと。入口が消えたら、若手はどこで鍛えるのか。鶏と卵なんですよね。

ただ、答えは案外シンプルかも。入口が消えたのはAIにさらされた花形職種だけで、仕事は選ばなければいくらでもある。まだ入口が残ってる現場で経験を積んでから戦えばいい。近道せず遠回りする。AIが"できる人"を強くする道具である以上、遠回りしてでも自分を"できる人"側に持っていく——今できるのは、たぶんそれくらいだと思います。
