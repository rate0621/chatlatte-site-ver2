# X投稿（本文）

「残業は悪」「残業ゼロが正義」——この空気に、正直ちょっとだけ引っかかっています。言いたいことは分かるんです。ただ、一括りに「残業＝悪」と決めつけるのは、少し主語がでかい気がして。

残業って、大きく分けて二種類あると思うんです。上司や会社からの命令でやる残業と、自分から進んでやる自主的な残業。「悪い」と言われがちなのは前者ですよね。やりたくもないのに断れず、だらだら付き合わされるやつ。これは確かに良くない。でも、この二つをまとめて「悪」にすると、本当は悪くない残業まで一緒に捨ててしまう気がするんです。

自主的な残業について言うと、僕はむしろ肯定的です。なんでか自分でもうまく説明できないんですが、炎上しているプロジェクトでも、真剣にゴールに向かって手を動かしていると、だんだん楽しくなってくる。徹夜も含めて残業してきたことは、間違いなく今の血肉になっているし、評価もされました。あの時間があってよかったと、今でも思っています。ちなみに今は、ほとんど残業しません。それでもそう思う。

ただ、ここは正直に書いておきたいんですが、「だからみんな残業しろ」とは言いません。それこそ主語がでかい。人によって事情も体力も違うし、そもそも成長は残業とは別の話です。残業しなくたって成長はできる。僕はたまたま、その場が残業だっただけです。

じゃあアリな残業とダメな残業を、どこで分けているか。いちばんの基準は「自分が納得しているか」。命令でも納得できるならアリだし、自主的でも納得しないままだらだら続けるなら違う。そしてもう一つ、これは絶対の上限ですが、体を壊すならダメ。どれだけ納得していても、健康より優先していい残業なんてない。

結局「残業は悪」でもないし「残業しろ」でもない。納得して、体を壊さない範囲でやるなら、別に悪いものじゃない。それだけの話だと思うんです。
