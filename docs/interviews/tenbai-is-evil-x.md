# X投稿（本文）

知り合いがポケカを集めてるんですが、最近よく怒ってます。人気商品が買い占められて、まともに買えないと。

その話を聞いて「転売ってそんなに悪いことかな」と考えたので、白黒つけずに整理してみました。

正直、僕は転売を頭ごなしに悪だとは思ってません。安く仕入れて高く売るのは商売の基本だし、早起きして並んだり抽選に応募したりの手間の対価、という見方も成り立つ。

ただ、線はあります。①生活必需品（マスク・薬みたいな"ないと困るもの"）の買い占めはダメ ②公式が「転売禁止」と言ってるものは論外。この2つを超えたら商売では済まない。

じゃあポケカは？嗜好品だし、公式が全面禁止してるわけでもない。僕の線引きだと「まあ商売」寄りなんですよね。友人の怒りは本物だけど、それを転売する人だけにぶつけるのが筋かというと、言い切れない。

「買えない」は誰が解決する問題なのか。メーカーは"卸した後は知らない"姿勢に見えるし、お店の対策は現場負担が重い。犯人を一人に決めても解けないんです。

そんな中、ポケモン公式がこの夏からマイナンバー本人認証を抽選に導入するそうで。1人1アカウントに紐づけて買い占めをやりにくくする"仕組み"の対策。人を責めるより、こっちのほうが現実的だなと。

結局きれいな答えは出ませんでした。でも、犯人探しの前に事実を並べて各自が線を引く。それも悪くないと思います。
