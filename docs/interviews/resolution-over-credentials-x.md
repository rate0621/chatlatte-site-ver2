# X投稿（本文）

「これをやって売上10億円上げました」より、「その中でどういうことがあったのか、どれだけ解像度高く話せるか」の方がずっと重要だと思っています。

前回書いた通り、統計検定の参考書まで読み込んで臨んだ仕事でしたが、実務ではほとんど役に立ちませんでした。役に立ったのは、専門的な話を相手のレベルに合わせて翻訳する力の方でした。

知識のインプット量は紙の上では測れます。資格やスキルシートに書けるのもたいていこの手の知識。でも、それが実際の場面でどう使われたかは、資格の欄には書かれていません。

信頼できるベンダーを探すのって、結局ガチャみたいなところがあります。一緒に仕事してみないと本当のところは分からない。でもガチャだからって何も見ずに引くわけにはいかない。契約前にできる数少ない確認が、会話の中でどれだけ具体的に、実体験として語れるかだと思っています。

「これくらいの規模の案件をやりました」で終わる人と、「その案件ではこういう場面があって、こう判断しました」まで話せる人とでは、安心感がまったく違う。

振り返ると自分自身、この基準の恩恵を受けて今の仕事に就いた側の人間です。大学も出ていないし統計の知識もない状態で、それでも採用してもらえた。見られていたのはたぶん、課題感や興味をどれだけ自分の言葉で話せるか、だったんだろうと思います。
