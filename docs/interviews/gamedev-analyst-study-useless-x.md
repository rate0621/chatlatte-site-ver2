# X投稿（本文）

統計検定の参考書まで読み込んで、データアナリストという仕事に臨みました。

「漫画でわかる統計」から入って、回帰分析みたいな手法を使いこなす人になるんだろうな、と勝手にイメージしてたんです。実際、前任者もそういう畑を歩いてきた人でした。

でも入社してから分かったのは、チームは誰もそんなものを求めていなかったということ。

それどころか「アナリストって人たちは、よくわからないことを偉そうに話す連中」って思われてました。面接で言われた「データ分析に課題がある」の意味が、ここでようやく分かった気がしました。

やったことは統計の勉強じゃなくて、真逆でした。発表で専門用語を使うのをやめて、シンプルに「平均」レベルの話にする。ただし切り方は工夫する(戦力別、課金額別とか)。あと発表の後にラノベの話とかどうでもいい雑談を挟む。

そしたら「さっきの話なんだけど」って個別に声をかけてくれる人が増えていったんです。

専門的なことを、あえて難しくせずに伝える。相手のレベルに合わせて言葉を選ぶ。この感覚は今もそのまま残ってる気がしていて、統計の勉強そのものより、当時いちばん身についたのはこっちだったんだろうなと思います。

続きはブログに書きました。
