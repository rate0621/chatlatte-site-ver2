# X版：見積もり7万円の解剖

## 本文ポスト（コピペ用・リンクなし）

サイトのテキスト修正とバナー差し替えで、見積もり7万円。

ご一緒していた会社では、それが当たり前の運用でした。ある時期、予算が苦しくなって「やれませんか？」と相談が来て、私が引き受けてみたら——実作業は数分でした。

「じゃあ7万円はぼったくりじゃないか」と思うかもしれませんが、そうとも言い切れないんです。ベンダー側で見積もりを組み立て直すと、

・窓口対応
・実装
・コードレビュー
・動作確認
・デプロイ

どれも仕事として受ける以上は省略できない項目で、それぞれに最小工数を割り当てて単価を掛けると、だいたい7万円になります。杓子定規に見積もると、そうなってしまう。

車検と同じ構造です。部品は安くても工賃は高い。でも自分たちではできないから、お願いするしかない。その工賃には、積み上げてきた技術への対価が含まれています。

ただ、機械的にはそうだとしても、私は商売としてはそれがいいと思っていなくて。普段からご一緒している会社の簡単な修正なら「それくらい、やっておきますよ」と言うことにしています。小さな修正の恩は、大きな改修のときの「納得して発注してもらえる」で返ってくるので。

じゃあ社内にエンジニアがいない会社はどうすればいいか。明日からできる工夫が2つあります。

1. 修正はまとめて依頼する。1件ずつ頼むと毎回デプロイ費用がかかりますが、5件まとめればデプロイは1回で済むはず
2. 大きな改修の「ついで」にしれっと混ぜる。作業が立ち上がっているときの追加は、ベンダー側も受けやすい

見積もりの構造（作業そのものより、前後の段取りにお金がかかっている）が分かると、この工夫は自然に思いつけるようになります。
