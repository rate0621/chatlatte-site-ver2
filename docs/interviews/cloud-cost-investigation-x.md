# X版：クラウド費垂れ流しの実録

## 本文ポスト（コピペ用・リンクなし）

「クレジットカードの期限が切れていて引き落としができません」

ある日届いたこの連絡が、誰も知らない月数十万円の入口でした。

調べると、それはAWSの利用料。でも問題は金額じゃなくて、その費用が「誰が・何のために使っているものなのか」社内の誰にも分からなかったことです。

アカウントをもらって中を覗いても、手がかりなし。ただサーバーは動いたままだったので、「これ使っていますか？」と各部署に聞いて回ったら、答えは全部「使っていない」。誰も使っていないサーバーに、毎月数十万円が払われ続けていました。

経緯をたどると、昔のサーバー移行で不要になった環境が、当時の担当者の退職でそのまま放置されていたようでした。「移行したら消そう」と言っていたはずが、消す作業にはリスクがあるから、正直やりたくない。だから後回しになる。

放置の正体は、技術の問題じゃなくて心理の問題なんですよね。

お掃除は、Slackで全員に見える形で宣言してから、バックアップ→停止→確認→削除の順で進めました。実は停止した瞬間にちょっとした本番影響が出たことがあって（誰も存在を知らない本番リソースがあった…）、段取りを踏む大事さを改めて感じました。

もうひとつ大事だったのが、決裁者への一言。偉い人は「消していいよ」と簡単には言えません。何かあったら困るから。だから「バックアップは取ってあります。何かあっても私が戻します。安心してください」まで伝えるのが仕事でした。

結果、月10万円以上の削減。3ヶ月、本来業務の片手間で。

同じことはたぶん、どの会社でも起きています。カードの明細をひとつひとつ、「どの部署の何の費用か」を書き出してみてください。経験上、絶対になんかあるので。
