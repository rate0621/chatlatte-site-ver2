# X投稿（本文）

『AIが答えを出せない 問いの設定力』にこんな一節がありました。「生成AIから提案される内容は、どれも間違ってはいない。しかし、いずれも決め手にかける」。

AIの案は正しいのに、なぜか決まらない。正直、自分はお客さんがそれで止まる場面には出くわしたことがないんですが、読んで別のことを思いました。

今って、目の前で言われた「内容」より「誰が言ったか」のほうが重みを持つようになってる気がするんです。

たとえば、開発をお願いしているベンダーが「この方針で」と言っても、チームでは「正直ちょっと不安だね」という空気になる。ところが同じ流れで私が「これでいいと思いますよ」と言うと、すんなり通ってしまう。内容はほぼ同じ。技術的にはベンダーのほうが詳しいのに、です。

でもこれ、私が偉いからじゃないんですよね。効いてるのは「その人の人となりを知ってるか」だと思う。長く一緒にやってきて、私がどういう人間かを知ってくれているから「この人が言うなら」となる。

ここまで考えて、AIに足りないものが見えた気がしました。背景です。

AIが提案してきても、なぜそれを言っているのか、その裏側は見えない。でも人間が言うときは「この人は実際に困ってて、なんとかしたくて言ってるんだな」という切実さが伝わる。信用って、案の正しさより、その背景で決まってる気がするんです。AIにはそれがない。人にはある。たぶんその差。

だからAIを使うなら、ありそうな課題を探させるんじゃなくて、自分が本当に困ってることを起点に相談する。その背景が周りに伝われば、人は協力してくれる。決めるのは、最後はやっぱり人なんだと思います。
