# X版：AIで月150時間削減の裏側

## 本文ポスト（コピペ用・リンクなし）

「AIで月150時間削減」って書くと魔法みたいに聞こえるんですが、実際は地味な話なので裏側を書きます。

ご一緒していたのは、記事1000件超のオウンドメディアを運営する組織。5年分の古い記事をリライトするプロジェクトが動いていたんですが、1記事に半日＋レビューの時間がかかっていて、先の長い話になっていました。

定例会議でその話が出たとき、「それ、AIに任せてみるのはどうでしょう」と軽く提案してみたのが始まりです。

作ったのは、記事にチェックを付けて「作成」を押すとAIがルールに従ってリライトし、人が確認して「入稿」を押すだけの社内ツール。人の仕事が「書く」から「確認する」に変わりました。

意外に思われるかもしれませんが、動くものができるまで1日かかっていません。時間がかかったのはそこからで、コンテンツチームのレビューでいちばん多かった指摘がこれでした。

「うちのメディアっぽくない」

事実の間違いじゃなくて、5年かけて築いた「らしさ」が出ていない。AIの品質問題の正体って、実はこっちなんですよね。ルールを直してはプロにレビューをもらう往復に、いちばん時間を使いました。

結果、半日かかっていたリライトが1時間で10本以上に。そこから月150時間の削減です。浮いた時間はSEOや企画という「人間の知恵を使う時間」に変わっていきました。

この経験から思うのは、AIに任せていい仕事は「すでにルールが定まっている仕事」だということ。ルールを決めるのは人間、作業はAI、最後の確認はまた人間。このサンドイッチにできる仕事なら、AIはしっかり働いてくれます。
