# X版：人手不足×AIの現実

## 本文ポスト（コピペ用・リンクなし）

「人手不足はAIで代替できる」——経営トップの6割がそう見ている、という報道がありました。

私は実際にAIで月150時間分の作業を"代替"した側の人間ですが、正直な第一声はこうです。作業は楽になります。でも、人手不足は解消されないと思います。

150時間分の作業が消えた現場で何が起きたかというと、誰も暇になりませんでした。浮いた時間はSEOや企画という次の仕事に流れていった。仕事はひとつ消えると、次が来るんですよね。AIで手に入るのは「人が余る未来」ではなく「事業のスピードが上がる未来」です。

そもそも「人手不足」という言葉が漠然としすぎているので、5つに分けて正直に答えてみます。

1. 業務が多すぎて手が回らない
→ なんとかなります。いちばん効果を出しやすい

2. 採用できない・シフトが組めない
→ 難しい。現場は人がいてナンボ。ただ現場の人の事務作業を切り出して「時間を現場に返す」ことはできる

3. できる人がいない（スキル不足）
→ ここがいちばん誤解が多い。自分ができないことをAIにやらせると、出てきた答えが正しいか判断できないんです

4. 「あの人」しかできない仕事がある
→ 負荷は減らせるけど、休まれたら止まる。これはAIより引き継ぎの問題

5. 成長に採用が追いつかない
→ 正直よく分かりません（分からないことは分からないと書いておきます）

3番の話をもう少しだけ。AIは、もともとできる人をより強くする道具であって、できない人をできる人に変えてくれる道具ではないと思っています。AIの答えをファクトチェックまでできる人って、かなりレアなので。

だから会社単位でも、判断できる人がいる会社ほど得をして、格差は広がっていくんだろうなぁと。

「人手不足をAIでなんとかしたい」の前に、まず「どうして人手不足だと思うのか」の整理からだと思います。AIはその後の、手段の候補のひとつです。
