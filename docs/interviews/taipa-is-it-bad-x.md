# X投稿（本文）

「タイパ重視で倍速・要約・ネタバレはけしからん、作品を味わえてない」ってよく言われますが、僕は「別にいいじゃん」派です。

ただ、なんでも効率でいいと思ってるわけでもなくて、自分なりの線引きがあります。

まず、どっちの言い分も分かる。時間は有限だし効率化は合理的。でも「じっくり味わってこそ」も分かる。どっちが正しいって話じゃない。

一つだけ大事にしてるのは、自分と違う楽しみ方を否定しないこと。タイパ批判って"自分の楽しみ方のほうが上"って見下しになりがちなんですよね。でも自分が正しいのと同じくらい、別のやり方を正しいと思ってる人もいる。

自分の使い分けはこうです。映画は等速で観る。倍速にしない。でも「◯◯の使い方」みたいな解説動画は倍速か10秒スキップで気になるとこだけ。

この差は何かというと「過程そのものに価値があるか」。映画はシリアスなシーンの"溜め"があるから面白い。結末より過程を楽しみたい。倍速だとその溜めが潰れて台無し。解説動画は結論が欲しいだけだから飛ばしていい。

つまり"タイパ派 vs じっくり派"の対立じゃなくて、同じ人でも対象によって過程の価値が違うだけ。本も同じで、小説はスキマ時間でも過程を楽しむし、ビジネス書は基本要約。やり方にはこだわらない。

人の楽しみ方に優劣つけなくていいと思うんですよね。
